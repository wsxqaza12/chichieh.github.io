I’ve been using all kinds of vibe coding tools intensively lately: v0, Lovable and Bolt for web design, and Cursor, Codex and Augment for code.

What I feel deeply is that these tools can get you to an initial goal very quickly. But as you keep developing in depth, if you don’t have solid development experience, vibe coding puts you in a state that “looks lightning fast but is actually chaos,” and debugging later ends up taking an enormous amount of time 🫠.

From my experience building a platform, before you use vibe coding, be sure to plan the user flow, system architecture, data schema, API spec and so on first. Only then can you give precise prompts. Don’t think vibe coding can read your mind and take care of it for you 😂 (I got lazy on a few feature pages, and debugging them was more painful than writing them from scratch by hand.)

So given what vibe coding can do right now, I don’t think engineers will be replaced any time soon, especially those who can do system design and architecture planning. Reading minds is still one of our advantages 😆

Side note: v0’s current pricing is really baffling, and lots of users have migrated. Right now I use Cursor (or Augment) + shadcn and get about the same results. Where has everyone moved to?
