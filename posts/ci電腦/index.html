最近我把十二年前組來打遊戲的電腦搬出來，幫我跑程式的自動化測試。

起因是這陣子在用 AI Agent 大整修 Cairn。現在靠 Agent 幫忙寫程式，開分支跟發 PR 的速度變超快，以前要刻半天的功能現在幾分鐘就改完了，結果整個開發瓶頸反過來卡在後面的 CI。每次改動都要跑自動化測試跟建置，確認程式沒被改壞，當 PR 越開越多，GitHub Actions 有時候一天就燒掉超過 25 美元。後來把家裡的電腦拉進來幫忙跑，連我的主力機都在兼差，變成我自己開發的時候一直被拖慢 😅

為了找地方讓測試跑，我開始打起以前那些舊電腦的主意。其實這些電腦不是我自己留著的，是我以前每次升級淘汰下來就會留給我哥，陸陸續續也給了兩三台。也因為都交給他保管，這些十幾年前為了打電動買的零件，才沒有被丟掉或賣掉，一路保存到現在。

我很喜歡玩遊戲，以前每次組電腦預算都抓在三萬元以內，在預算裡挑 CPU、顯卡跟記憶體，把錢花在刀口上本身就是件很開心的事。十二年前我第一次自己挑零件組的那台，用的是 i5-4690、R9 270 跟 32GB RAM，這次從我哥那邊搬回來，散熱器上還留著一張寫著「103.06.08」的貼紙。看到民國 103 年這個日期，還滿感慨地，當時完全沒想到它會用這麼久。

還好我哥一直有陸續在用，本來只是想接上線試試看，結果直接灌完 Ubuntu 26.04 LTS 就能進系統，完全沒有老機器動一下卡半天的慘狀。看著十二年前花不到三萬塊組的電競機，跑起現在的作業系統幫我接 CI 工作，那個感覺真的滿奇妙的，有一種因為它還能用、又再開心了一次的感，花一次錢兩次享受 🙌

除了這台，我也把七年前組的 Ryzen 5 3600 搬了出來。那台電腦用的是 be quiet! 的機殼，裡面零件換了幾輪，機殼一直用到現在，也是我第一次接觸貓頭鷹風扇XD。它在 2024 年底因為主機板壞掉退了下來，我才在去年初把主力機換成 AM5 平台的 R7 7700。當時大概也沒想到，現在因為算力不夠，我又在 momo 花了 2,500 元買一張 B550M 主機板，把這顆沒壞的 3600 重新救回來上工，準備讓它一台同時跑兩個 Runner。

整理到這裡，才發現自己不知不覺湊出了一個家庭號的 CI 工作池。算一算手上有 i5-4690、一台救回來的 R5 3600、一台 Mac mini M4、一台灌了雙系統的 N100 小主機，再加上兼差的主力機 R7 7700。靠 AI 開發產品，最後居然開始煩惱這麼多台電腦要怎麼分工 🤣

以前挑電腦只在意遊戲跑得順不順，現在看的都是這台適合接什麼測試、記憶體夠不夠同時跑兩份工作、能不能不要再占用我的主力機。不過省下來的 GitHub Actions 雲端費用，最後會不會全部換成我找零件跟維護環境的時間，這點還很難說，光這幾天裝系統跟搞環境就已經很有感了 🫠

至於那台被解放出來的主力機，我最近其實也買了一顆 Ryzen 9 9950X 準備換上去。那又是另一段折騰了，之後再跟大家分享！
