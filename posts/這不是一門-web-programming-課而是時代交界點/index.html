這文章快一個月了，之前剛看到文章滿感動的，這是一門共 15 週，沒放過半天假的 Web Programming 課，在去年 12 月結束了，很感謝 Chung-Yang (Ric) Huang 教授的分享教學。

這門課的核心觀點很清楚也很符合趨勢： 在 AI 時代，用自然語言寫程式，會像寫文章一樣平常； 所以「會不會寫 code」不該再是門檻，而應該是一種基本素養。

這門課不是要把每個人都訓練成 Software Engineer，而是讓想做東西的人，真的有能力把想法做出來。

更讓我佩服的是這個黃教授的課程講義 + 上課影片，全部無償開源，沒有精剪、沒有包裝、就是把真實的教學歷程完整留下來。這在現在什麼都要變現、什麼都要包成課的環境裡，真的難能可貴。

而且從課綱來看，這根本不是入門玩具課： 從 HTML / DOM / JS 一路到 React、TypeScript SPA、Full-stack、資料庫、OAuth、Serverless Next.js、Realtime、Chatbot、Agentic AI Flow 最後直接談 From Projects to Startups

這條學習路線，本來應該要踩很多坑跟花費數年才能摸熟， 現在直接有前輩帶著你一次把 AI coding + Web + 產品 + 專案 + 創業視角 放在同一個視角看，能全面的瞭解並融會貫通很多事情。

我特別有共鳴的是黃教授說開源之後，課程內容如果能靠社群一起演進，也許比每年重開一次課，更符合 AI 時代，這也是我很努力在做的事。

這其實是一個很大的命題，到底知識該不該被侷限在課程裡? 還是應該成為一個能持續更新的公共資源? 參照國外很多 MOOC 甚至 YT 免費課，我個人更傾向的是後者。

如果你對 AI coding 有興趣，但不想只停在 prompt，想做 side project、甚至想過 startup

那這份開源內容，真的值得收藏反覆觀看。 也期待有一天，真的能看到黃教授提到的 WP-2
